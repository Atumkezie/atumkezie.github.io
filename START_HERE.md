## Preview first

Open **OPEN_PREVIEW.html** from this extracted folder. Keep the `review/` folder alongside it so the résumé, project pages, and keyboard performance work.

## Make it live

1. Create a public GitHub repository named **hk0922.github.io** under **HK0922**.
2. Follow **[docs/GITHUB_PAGES.md](docs/GITHUB_PAGES.md)** to upload the source and select **GitHub Actions** as the Pages source.
3. The included workflow builds, checks, and publishes the static site. After the deployment succeeds, your address will be **https://hk0922.github.io/**.

The guide includes GitHub Desktop and terminal instructions, updates, troubleshooting, and a short live-site check. No paid service, model key, database, or application server is needed for this portfolio.
